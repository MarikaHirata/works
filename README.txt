Marika Hirata — Works 2025–2026（Webスライド）

URL: https://marikahirata.github.io/works/

← → キー、画面の左右タップ、スワイプでページ送り。F で全画面、I（または INDEX）でサムネイル目次。
iPad では Safari の共有ボタン →「ホーム画面に追加」で、全画面のアプリとして開けます。発表中は画面が暗くなりません。
目次の「この端末に保存」を一度押しておくと、ページの画像はネットがなくても表示されます（動画・音楽・YouTube は接続が必要）。
作品の扉ページでは YouTube の本編がその場で再生されます。
♪ のボタンで主題歌が流れます（ページを移動しても鳴り続け、左下のバーで位置を変えたり止めたりできます）。
表紙とプロフィールの RADIO で、茉莉花のインタビューの声が流れます（ページを移動しても続きます）。
広告の仕事のページは、映像をクリックすると本編が音つきで再生されます。
ホシノメの扉ページの PLAY THE DEMO は itch.io のデモを開きます（パスワード: was_here）。
フォルダごと手元で開くときは「スライドを開く.command」をダブルクリック（index.html を直接開くと YouTube はページ内で再生されません）。
