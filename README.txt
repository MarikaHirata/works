Marika Hirata — Works 2025–2026（Webスライド）

「スライドを開く.command」をダブルクリックすると、ブラウザで開きます（初回は右クリック →「開く」が必要なことがあります）。
このフォルダごと Web サーバーに置けば、URL で共有できます。
index.html を直接開いても見られますが、その場合 YouTube はページ内では再生されず、サムネイルから YouTube が開きます。
← → キー、画面の左右タップ、スワイプでページ送り。F で全画面、INDEX で目次。
作品の扉ページでは YouTube の本編がその場で再生されます（ネット接続が必要）。
ホシノメの扉ページの PLAY THE DEMO は itch.io のデモを開きます（パスワード: was_here）。
